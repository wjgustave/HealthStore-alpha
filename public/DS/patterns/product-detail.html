Product detail (PDP)

The most complex surface in the product: a hero, a persistent decision-snapshot strip, tabbed content, and a sidebar. It composes badges, tabs, cards, collapsibles, tables and CTAs into a single commissioning view.

Anatomy

  1. Breadcrumb — Home / Find apps / [product].
  2. Hero — logo, name, supplier, value proposition, trimmed signal badges, one primary Express interest CTA + a quiet Save / Compare / Share utility cluster.
  3. Decision snapshot strip — persistent 4-up summary (platform, indicative cost, integration capability, live deployments).
  4. On this page — sticky sidebar nav (right on desktop) with anchor links to narrative and reference sections.
  5. Narrative spine — for curated products: problem → how it helps → local value → how to buy → assurance → making it work → NHS experience (deployment register + case studies, moved out of the tabs to avoid duplication).
  6. Tabs — Evidence, Deployment & adoption, Commercial, Technical & integration.
  7. Sidebar — supplier contact, demo access, share/print.

Hero

One primary action. Express interest is the sole filled CTA; Save / Compare / Share sit in a quiet, tinted utility cluster (44px targets, consistent icon + label). Hero badges are trimmed to condition + decision signals (maturity if not “Established”, content confidence) — supervision model, NICE references and the NHS App badge sit in the commissioning snapshot and detail sections.
