Widget states

Widgets fetch through BookmarkProvider / EoiProvider, which expose status: 'loading' | 'ready' | 'error'. Each widget branches on status so a failed fetch never reads as a genuinely empty list. WidgetShell ships WidgetMessage (loading / empty) and WidgetError (an assertive alert + a “Try again” Button bound to the provider’s refresh()).

Stat tiles show a skeleton bar while loading and a muted “—” (with an sr-only “couldn’t load”) on error, so 0 only ever means a genuine zero. A 401 surfaces a soft “your session may have expired” notice (DashboardSessionNotice) rather than blank widgets.
