Patterns

Comparison tool

Side-by-side evaluation of selected DTx apps. Users build a basket (up to four, same condition area), then read a single grouped decision workspace — collapsible attribute groups filtered by a task “lens” and an optional differences-only toggle.

Vocabulary is “DTx app”, and the catalogue/PDP add control reads “Add to compare” / “Added”.

Decision workspace

Collapsible attribute groups stacked vertically; decision-critical groups open by default. Selected DTx apps run as aligned columns, and the summary + group grids scroll horizontally rather than overflowing the page with 3–4 apps.

Differences-only empty state

When “Only differences” is on and the selected DTx apps match on every dimension, the workspace shows a real empty state with a “Show all rows” button (which turns the filter off) instead of a silently blank panel.

No differences to show

The selected DTx apps match on every comparison dimension. Turn off the filter to see the full comparison.
