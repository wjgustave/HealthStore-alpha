Loading & skeletons

Placeholder UI shown while content loads (catalogue and comparison routes use Suspense skeletons). Skeletons preserve layout and reduce perceived wait, with a subtle shimmer that respects reduced-motion.

Catalogue card skeleton

Line skeletons

Guidance

  • Match the skeleton to the real content's layout to avoid shift on load.
  • Use skeletons for first loads; use inline spinners/aria-busy for in-place updates (e.g. Save toggle).
  • Keep shimmer subtle; it disables under prefers-reduced-motion.

Accessibility

  • Wrap loading regions in an aria-busy="true" container, or announce status via an aria-live region.
  • Skeleton shapes are decorative and should not be announced individually.
