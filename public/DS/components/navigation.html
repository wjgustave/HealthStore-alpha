Components

Navigation

The global header, the breadcrumb trail, and the back-to-top control. Together they express the site information architecture: Home is L1; Find apps, Comparison tool and Funding directory are L2 peers.

Primary header

A static white header with the brand, a "Prototype" badge, top-level links and (when signed in) an AI Advisor entry and a second context row.

The Comparison tool link carries a live count badge from the compare basket. Active links use blue text on a #E6F0FB tint.
Active-state matching. “Find apps” owns the whole /apps branch — the catalogue and product pages (/apps/[slug]) — via prefix matching (path === '/apps' || path.startsWith('/apps/')), so a PDP does not leave the header with nothing highlighted. Exact-match routes (Dashboard, News) stay exact.

Breadcrumb

The PageBreadcrumb component. Home is prepended automatically; the current page is non-linked primary text. Every signed-in page carries one — for example Home / Organisation settings on org-settings.

  1. Home
  2. /
  3. Find apps
  4. /
  5. Clinitouch
<PageBreadcrumb items={[
  { label: 'Find apps', href: '/apps' },
  { label: 'Clinitouch' },
]} />

Back to top

A fixed pill button that appears after scrolling 400px. Maps to .ds-btn--primary .ds-btn--pill.

Accessibility

  • Header is a <header>; nav groups are <nav> with labels.
  • Breadcrumb uses an ordered list with aria-current="page" on the last item; separators are aria-hidden.
  • The mobile menu toggle has an accessible label and the count badge is mirrored in the link's aria-label.
