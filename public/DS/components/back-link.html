Back link

The NHS nhsuk-back-link. Used at the top of every step of a multi-step journey (see the Multi-step journey pattern) so users can move back one step without losing their answers. Rendered as a <Link> when it navigates to a route, or a <button> when it moves between in-page steps.

Component
components/eoi/ExpressInterestJourney.tsx (BackLink)
CSS
nhsuk-back-link (nhsuk-frontend)

Example

Back 
<div class="nhsuk-back-link">
  <button type="button" class="nhsuk-back-link__link">
    <svg class="nhsuk-icon nhsuk-icon__chevron-left" …></svg>
    Back
  </button>
</div>

Behaviour & accessibility

  • Every journey step gets a working back control — never a dead href="#".
  • Going back preserves the user's answers (state is kept in the journey client).
  • If the user arrived via a Change link on Check your answers, back returns to Check your answers.
Source: nhsuk-frontend back link, compiled into app/styles/nhsuk-theme.generated.css. First used by the Express interest journey.
