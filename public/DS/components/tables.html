Tables

Tabular data appears in two main forms: the PDP "Where it's live" deployment register, and the comparison workspace. Both use bordered, scannable rows with status badges and scroll horizontally where the columns exceed the viewport.

Deployment register (PDP)

Status-filterable rows: each row carries ICB, place, care setting, status and confidence. Rows expand for detail.

Comparison workspace

DTx apps as columns, attributes as rows, grouped into collapsible sections. Critical rows get a blue left marker. The summary + group grids scroll horizontally (keeping columns readable) instead of overflowing the page with 3–4 apps.

Accessibility

  • Use real <table> markup with <th> and scope attributes.
  • Status is always carried by a text badge, not colour alone.
  • Expandable rows use buttons with aria-expanded.
  • Comparison view announces row counts via an aria-live region.
