Accessibility

  • Every field has a programmatically associated <label>; hints use aria-describedby.
  • Errors set aria-invalid and reference an role="alert" message.
  • Radio/checkbox groups use <fieldset> + <legend> (may be sr-only).
  • Focus shows the global yellow :focus-visible outline; never remove focus styles.
