Components

Toggles & segmented controls

Controls that switch state or filter options. Save / Compare toggles render through components/ui/Button.tsx (variant="toggle") with the NHS 4px press shadow. Comparison lens and diff controls use dedicated .hs-compare-* classes.

Save toggle

Catalogue cards and the PDP utility cluster. Label changes with state: Save → Saved. Uses SaveToggleButton → Button variant="toggle".

Add-to-compare toggle

The catalogue / PDP control that adds a DTx app to the comparison basket. Label changes with state (CNT-02): “Add to compare” → “Added”. When the basket is full or the condition differs it becomes aria-disabled with a reason, staying in the tab order (shadow removed when disabled).

PDP utility cluster

Share (secondary, size="sm", bordered), Save and Compare (bordered toggles, size="sm") in a quiet tinted bar. Allow extra bottom padding so the 4px press shadow is not clipped.

Lens control (segmented options)

A task-focused filter set rendered as a fieldset of selectable options (flat — no NHS press shadow).

Accessibility

  • Save / Compare toggles set aria-pressed; label text changes with state (never icon-only).
  • Press shadow flattens on :active for tactile feedback; disabled / aria-disabled removes shadow.
  • Lens options are wrapped in a <fieldset> with a <legend>.
  • All interactive controls meet the 44px minimum target height.
