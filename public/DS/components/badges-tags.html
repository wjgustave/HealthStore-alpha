Badges & tags

Small, non-interactive labels that communicate status, category or metadata. Built on a single .badge base with semantic colour modifiers.

Base class
.badge
Source
components/Badges.tsx

When to use

  • To label an item's status (DTAC passed, evidence strength, maturity).
  • To tag a category (condition, NICE type, topic).
  • For short, scannable metadata inside cards and tables.

When not to use

  • For actions — use a button.
  • For long text — badges are for one to three words.

Interactive chips (.pill)

Static metadata stays a square .badge; removable or clickable chips (filter pills, tag editors, AI follow-ups) use the rounded .pill.

COPD × Remote monitoring × Funded service

Accessibility

  • Badges are decorative labels — keep the meaning in adjacent text where colour carries status.
  • Do not rely on colour alone; the text label is the source of truth.
  • Badge colour pairs meet AA contrast for their text on tint.
