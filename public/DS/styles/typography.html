Matches the nhsuk-frontend responsive type scale (core/settings/_typography.scss). Sizes step up at the NHS tablet breakpoint (641px); the values shown are the desktop step. Resize the window to see the responsive step-down.

Heading colour

All heading levels (H1–H3) default to --text-primary (NHS black, #212B32). NHS blue is not a heading accent — reserve it for links and interactive controls.

DS site chrome (.ds-sidenav, code blocks, monospace meta) uses compact NHS token sizes where possible; monospace specimen meta remains fixed for layout stability.

Do

  • Use scale tokens rather than arbitrary rem/px sizes.
  • Keep one H1 per page; nest H2/H3 logically.

Don't

  • Hardcode font sizes inline (common in current pages).
  • Mix heading weight conventions across sections.
