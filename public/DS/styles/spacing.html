Spacing & layout

Recommendation. Adopt a named spacing scale (e.g. --space-1…--space-8) so spacing is as token-driven as colour and type. Today spacing is expressed via Tailwind classes and ad-hoc inline values.

Page container

In-app pages constrain content to a max-width and pad the gutters. The dominant convention is:

<main class="mx-auto max-w-7xl px-4 sm:px-6">
  <!-- page content -->
</main>
Max width
max-w-7xl (80rem / 1280px)
Gutters
px-4 (16px) → sm:px-6 (24px)
Card padding
p-5 / p-6 (20–24px)
Section rhythm
mb-6 / mt-8 (24–32px)

Minimum touch target

Interactive controls target a 44px minimum height (visible in .hs-compare-* controls and the proposed .ds-btn). Keep this for buttons, toggles, filter selects and tappable list rows.
