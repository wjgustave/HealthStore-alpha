Spacing & layout

Spacing follows the NHS spacing scale (nhsuk-frontend/core/settings/_spacing.scss): a 4px base grid with points 0–9. Tailwind shares the 4px base, so p-1/2/4/6/8/10/12/14/16 map onto NHS points; off-scale Tailwind steps (12px *-3, 20px *-5, 28px *-7, and fractional 2/6/10/14px) are avoided.

Tokens --space-1…--space-9 expose these points in CSS.

Page container

In-app pages use the .hs-page container: a centred ~1280px canvas with NHS gutters (16px mobile → 32px desktop).

Minimum touch target

Interactive controls target a 44px minimum height (visible in .hs-compare-* controls and the proposed .ds-btn). Keep this for buttons, toggles, filter selects and tappable list rows.
