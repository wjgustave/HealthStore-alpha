Contrast rule. --text-muted-low-con (#768692) is for non-body-line contexts only (e.g. meta on tinted panels). It does not meet AA against white for body copy — use --text-muted or darker for paragraphs.

Usage

Text colour roles

TokenUse forDo not use for
--text-primaryHeadings (H1–H3), section titles, default KPI values, static callout labelsLinks or button labels
--text-secondary / --text-mutedBody copy, descriptions, metaPrimary headings
--blue-tint-25KPI / metric value text that needs a blue accent (e.g. local-value tiles)Hyperlinks (use --nhs-blue)
--nhs-blueInline links, disclosure <summary> controls, text inside buttons and tabs, brand chromeKPI metric values (use --blue-tint-25)

Do

  • Reference colours via tokens (var(--nhs-blue), var(--blue-tint-25)), not hex literals.
  • Use --blue-tint-25 for blue KPI / metric figures; keep --nhs-blue for links and controls.
  • Use --text-primary for non-interactive headings and default (non-blue) stat values.
  • Pair semantic colour with an icon or text label, never colour alone.

Don't

  • Inline #005EB8 or #5694CA directly — use the tokens.
  • Use NHS blue for KPI metric text — that accent is Blue tint-25.
  • Use blue section headings that are not links.
  • Introduce new accent hues for one-off surfaces without documenting them here.
  • Use low-contrast muted text for body copy.
