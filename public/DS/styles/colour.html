Contrast rule. --text-muted-low-con (#768692) is for non-body-line contexts only (e.g. meta on tinted panels). It does not meet AA against white for body copy — use --text-muted or darker for paragraphs.

Usage

Do

  • Reference colours via tokens (var(--nhs-blue) or the nhs-blue Tailwind utilities), not hex literals.
  • Keep blue as the only interactive accent.
  • Pair semantic colour with an icon or text label, never colour alone.

Don't

  • Inline #005EB8 directly — use the token or nhs-blue utility.
  • Introduce new accent hues for one-off surfaces.
  • Use low-contrast muted text for body copy.
